Button — the primary clickable action element used across every screen.
```jsx
<Button variant="gradient" size="lg"><Zap size={16}/> Go</Button>
```
Variants: default (solid blue, most actions), gradient (blue→purple, AI/quick-add CTAs), outline (secondary actions like Filter), ghost (low-emphasis, "View all →"), destructive (delete/cancel), secondary (toggle pressed state), link (inline text action).
